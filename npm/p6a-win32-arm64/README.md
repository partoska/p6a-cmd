# @partoska/p6a-win32-arm64

This is the **Windows arm64** native binary for
[`@partoska/p6a`](https://www.npmjs.com/package/@partoska/p6a).

You should not install this package directly. Install the main package instead,
and npm will automatically pull in the correct binary for your platform:

```bash
npm install -g @partoska/p6a
```

See the [`@partoska/p6a` README](https://www.npmjs.com/package/@partoska/p6a)
for documentation and usage.
